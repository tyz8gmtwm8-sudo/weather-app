| [React](https://react.dev/) 19 | UI |
| [TypeScript](https://www.typescriptlang.org/) | 言語 |
| [Tailwind CSS](https://tailwindcss.com/) 4 | スタイリング |
| [OpenWeatherMap API](https://openweathermap.org/) | 天気データ |
